Add a Lottery Scheduler to xv6
In this project, you will replace the current round robin scheduler in xv6 with a lottery scheduler.

The basic idea is simple:
Assign each RUNNABLE process a share of the processor in proportion to the number of tickets it has. The more tickets a process has, the greater its probability of being selected. Each time slice, a randomized lottery determines the winner; that process runs for that time slice.

Setting Tickets
Implement a new system call to set the number of tickets for the calling process.
The prototype is:
int settickets(int)
This call sets the number of tickets of the calling process. By default, each process should get one ticket. A process can raise or reduce its number of tickets by calling this routine, and thus receive a higher or lower expected proportion of CPU time. The call should return 0 if successful and -1 otherwise (for example, if the caller passes a value less than one).

Implementing the Scheduler
Most of the scheduler code can be found in proc.c; the associated header file proc.h is also useful. Study the existing scheduler control flow and replace the round robin selection logic with your lottery scheduler.

A child process must inherit the same number of tickets as its parent. For example, if a process with 10 tickets calls fork(), the child should also begin with 10 tickets.

Your lottery must consider only RUNNABLE processes. You will also need a pseudo-random number generator that can run inside the kernel.

Getting Process Statistics
Implement a second system call to gather scheduling statistics. The prototype is:
int getpinfo(struct pstat *)
This routine returns information about processes, including whether a process-table slot is in use, the
number of tickets assigned to the process, the process ID, and the number of ticks the process has
accumulated. The ticks value should increase once for each time slice in which the process is selected to
run. The call should return 0 if successful and -1 otherwise (for example, if a bad or NULL pointer is
passed into the kernel).
Use the following structure exactly as shown in a file named pstat.h. Do not change the structure.
#ifndef _PSTAT_H_
#define _PSTAT_H_
#include "param.h"
struct pstat {
 int inuse[NPROC]; // whether this slot of the process table is in use (1 or 0)
 int tickets[NPROC]; // the number of tickets this process has
 int pid[NPROC]; // the PID of each process
 int ticks[NPROC]; // the number of ticks each process has accumulated
};
#endif // _PSTAT_H_
Good examples of how to pass arguments into the kernel can be found in existing system calls. In
particular, follow the path of read() to sys_read() and study how xv6 validates and uses pointers passed
from user space. User pointers must be checked carefully before the kernel uses them.
